# Картинки по названиям (надстройка Excel для Mac)

Вставляет картинки из файлов в ячейки Excel по названиям или артикулам, как PastePictures на Windows.
Картинки — обычные рисунки Excel, привязанные к ячейкам, поэтому файл с ними открывается
в любой версии Excel, включая 2016 и 2019.

Для работы самой надстройки нужен Excel для Mac 2021 или Microsoft 365.

## Что умеет

- Берёт названия из выделенного столбца, вставляет картинку в указанный столбец той же строки.
- Картинки из папки (с подпапками) или из выбранных файлов: JPG, PNG, GIF, BMP, WebP, HEIC, TIFF.
- Сопоставление: имя файла совпадает с ячейкой, начинается с текста ячейки или содержит его.
  Регистр и пробелы по краям не важны, русские имена файлов с Mac обрабатываются правильно.
- Вписывает картинку в ячейку с сохранением пропорций; по желанию задаёт высоту строки.
- Привязка: перемещать и менять размер с ячейкой / только перемещать / не привязывать.
- Уменьшает большие фото, чтобы файл не раздувался.
- При повторном запуске заменяет свои старые картинки, а не накладывает новые.
- Показывает список ненайденных названий и может закрасить такие ячейки.
- Удаляет все свои картинки с листа одной кнопкой.

## Установка на Mac

Надстройка — это веб-страница (папка `src`), которую Excel открывает в боковой панели.
Ей нужен адрес **https**.

Надстройка размещена на GitHub Pages: `https://alexhubka96.github.io/PastePicturesMac/src/`,
и `manifest.xml` уже указывает на этот адрес. Изменения в папке `src`, отправленные в репозиторий,
подхватываются Excel без переустановки (после перезапуска Excel).

### Подключить манифест в Excel

1. В Finder: «Переход → Переход к папке…» и вставить
   `~/Library/Containers/com.microsoft.Excel/Data/Documents/`
2. Создать там папку `wef` (если её нет) и положить в неё `manifest.xml`.
3. Перезапустить Excel, открыть любой файл.
4. «Вставка → Надстройки → Мои надстройки» (стрелка у кнопки) и выбрать «Картинки по названиям».
5. На вкладке «Главная» появится кнопка «Вставить картинки».

### Вариант без интернета (для проверки)

Если на Mac установлен Node.js, можно запустить локальный сервер. Перед этим в `manifest.xml`
заменить адрес GitHub Pages на `https://localhost:3000/`.

```bash
npx office-addin-dev-certs install
```

```bash
npx http-server src -S -C ~/.office-addin-dev-certs/localhost.crt -K ~/.office-addin-dev-certs/localhost.key -p 3000
```

Сервер должен работать, пока открыта надстройка.

## Проверка без Excel

- `node dev/logic.test.js` — проверки сопоставления и расчёта размеров.
- `dev/test.html` — панель с имитацией Excel. Открывать через локальный сервер
  (`python -m http.server` в папке проекта), затем в консоли браузера вызвать `__makeFiles()`.

## Ограничения

- Одна картинка на ячейку.
- Объединённые ячейки не учитываются: картинка вписывается в верхнюю левую ячейку.
- Картинки по ссылкам из интернета пока не поддерживаются.
